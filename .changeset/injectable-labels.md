Make every French default text of the bricks injectable, so an application can provide its own copy (for example English source text translated with `$localize`) once for the whole tree, a route or a component subtree. Each entry point that writes text exports a `Cw<Entry>Labels` type, its French defaults `CW_<ENTRY>_LABELS` and a `provideCw<Entry>Labels(labels | () => labels)` provider (`provideCwDataTableTexts` for the data table; tracker, entry form and entry list providers for the time tracker; zone and file providers for the dropzone; message, thread and tone providers for the message). Provided texts merge over those of the parent injector, then over the French defaults; a brick's text inputs and `labels` input still override them. `injectCwStatusLabels` and `injectCwPriorityLabels` return the status and priority words in effect, used by the badges and the timeline. Hard-coded texts that no input could change (toast « Annuler », attachment and avatar states, key names of shortcuts, result counts, pagination and stepper texts…) are now part of these labels. The French defaults are unchanged: an application that provides nothing renders exactly as before.
