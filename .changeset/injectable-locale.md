Make the locale of every date, number and file size written by the bricks injectable with `provideCwLocale(locale | () => locale)` from `@cadenway/ui/core`, so an English application gets English months, weekdays, times, relative times, numbers and sizes once for the whole tree, a route or a component subtree. The function form runs once in an injection context, for example `provideCwLocale(() => inject(LOCALE_ID))` to follow Angular's locale. It covers the avatar initials, block editor matching, chart, checklist due dates, data table dates and sorting, filter chip dates, message times, meter, pagination, stat, time tracker and time entry list, timeline ruler and periods, attachment and dropzone sizes (« Mo » in French, « MB » elsewhere). The `locale` inputs of `cw-calendar`, `cw-calendar-view` and `cw-date-picker` default to the provided locale and still override it; the date picker's typed date and its default hint (`inputPlaceholder`) now follow the order and separators of that locale (« mm/dd/yyyy » in `en-US`), always in the Gregorian calendar with Latin digits so the shown date parses back. Without a provider the locale stays `fr-FR`: an application that provides nothing renders exactly as before. Texts (« sur », « depuis », « du … au ») are not part of the locale.
