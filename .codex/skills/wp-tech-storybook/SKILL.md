# Storybook for Waypoint

Work in `waypoint-design-system` and inspect the component API, established story conventions, and token/theme skills. Add representative states and interactions for the requested component without creating a parallel component implementation. Use the repository's story, interaction, and accessibility checks when available; report missing scripts and visual verification limits.

Consult the official documentation for the version actually used: https://storybook.js.org/docs.
